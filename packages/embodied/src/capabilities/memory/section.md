# Memory
Cell `{{recipe_tag}}`. Memory is a read-only library of what earlier runs of this robot learned, at `{{memory_dir}}/` ({{memory_profile}} profile). Read it with `read`, `ls`, `grep` and `find`; `_internal/` and other robots' memory cannot be read, you write only to `{{output_dir}}/`, and you read nothing else on disk.

1. Before your first motion, read `{{memory_dir}}/MEMORY.md` if it exists: it indexes the general skill library, one line per memory saying when it applies. `grep` `{{memory_dir}}/global/` and `{{memory_dir}}/suite/` for your objects, container, fixture or words from the task, and read the one to three leaves that match this scene, choosing from the file body, not the index line.
2. Then the solved reference for this task, when present: `{{memory_dir}}/task_only/{{reference_tag}}.json` (the strategy notes) and `{{memory_dir}}/task_only/{{reference_tag}}_recipe.jsonl` (its command sequence). A recipe records the robot's own tool calls: take its order of stages, target parts and pitfalls, never its coordinates; when your tools are not the ones it names (action units, code), carry its stages over, not its commands.
3. A missing or empty memory is normal. Memory is strategy and pitfalls; the current images and task override it.
