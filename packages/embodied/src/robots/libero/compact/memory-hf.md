# Memory
Cell `{{recipe_tag}}`. Memory is a read-only library of what earlier runs of this robot learned, at `{{memory_dir}}/`. Read it with `read`, `ls`, `grep` and `find`; published memory cannot be written, and `_internal/` and other robots' memory cannot be read. Write only the audit, with `write`, to `{{output_dir}}/`. Do not re-read a file you already read in this session.

1. Read memory first, before your first motion. `{{memory_dir}}/MEMORY.md` indexes a general skill library (operating wisdom, magic numbers, gotchas, reusable manipulation patterns); each line says when a memory applies. Do not stop at the index, whose lines do not name every scene a memory covers: `ls` `{{memory_dir}}/global/` and `{{memory_dir}}/suite/`, or `grep` them for your objects, container, fixture, motion or words from the task text. A theme often has several near-identical files that differ only in which objects or step order; `read` the top candidates and choose the one whose objects, spatial relation and step order match your scene, deciding from the file body, not its index line. Take techniques and parameter ranges as general know-how; re-derive every coordinate by perception in this scene.
2. Then read the solved seed-0 reference for this task if present: `{{memory_dir}}/task_only/{{reference_tag}}.json` (the winning strategy notes) and `{{memory_dir}}/task_only/{{reference_tag}}_recipe.jsonl` (its command sequence). Other `<tag>.json` + `<tag>_recipe.jsonl` pairs in `task_only/` are references for other cells. They were built on other scenes, sometimes with older or oracle assumptions: reuse strategy notes, prompt ladders, primitive order, gotchas and qualitative target zones, but never copy coordinates and never replay a stale command list. A recipe is only the commands; the memory from step 1 carries the reasoning and failure modes needed to adapt it, so consult it even when a recipe exists.
3. Before `finish`, write the audit `{{output_dir}}/{{recipe_tag}}.json`: suite, task_id, seed, `regime: "strict_perception"`, `strategy_notes` (how you localized, what you did, and the exact memory file names you read, or "no matching task memory found"), `pick_result`, `final_state` (the latest `state`) and `terminated`. If the task is not solved, set `terminated: false` and say what you tried in this episode and where it stalled.
